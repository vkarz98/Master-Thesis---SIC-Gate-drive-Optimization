This repository contains the master thesis work on silicon carbide (SiC) gate-drive optimization, including the report, presentation, simulation code, experimental data, analysis scripts, and supporting literature.

## Featured deliverables

- [Master Thesis Report PDF](Karthikeyan_Vijayakumar_Master_Thesis_Report.pdf)
- [Master Thesis Presentation](MA_presentation_Karthikeyan_Vijayakumar.pptx)

## Project overview

The work focuses on switching behavior, gate-drive optimization, EMI-related performance, and comparative evaluation of gate-drive strategies for power semiconductor applications.

## Repository structure

- `src/matlab/` – MATLAB scripts, waveform analysis, and simulation workflows
- `src/simulation/` – simulation outputs and model-related results
- `src/hardware/` – PCB and hardware design files
- `docs/latex/` – LaTeX report sources and thesis document assets
- `docs/presentations/` – presentations, decks, and project slides
- `results/figures/` – plots and comparison figures
- `data/raw/` – raw data
- `data/processed/` – processed datasets
- `data/output/` – exported result tables and outputs
- `references/` – papers and technical references
- `assets/hardware/` – board and hardware images
- `deliverables/` – final report, presentation, and publication-ready files

## Notes

- MATLAB temporary files such as `.asv` are excluded from version control.
- LaTeX build artifacts are excluded to keep the repository clean.

## Usage

1. Open the MATLAB scripts in `src/matlab/` to reproduce analysis and plots.
2. Use the LaTeX sources in `docs/latex/` for report editing.
3. Review the final report and presentation from the `deliverables/` folder.
